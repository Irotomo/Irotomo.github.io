こんな交流会です

수업이나 정해진 주제 없이 자유롭게 이야기해요. 통역이 따로 있지는 않지만, 서로 아는 표현으로 천천히 대화하면 돼요.

授業や決まったテーマはなく、自由におしゃべりを楽しみます。通訳は付きませんが、お互いに分かる言葉を使いながら、ゆっくり話せば大丈夫です。

한 테이블에 4~6명씩

1テーブルに4〜6人

한국인과 일본인이 골고루 앉을 수 있도록 자리를 정해요. 한국어를 섞어 말하거나 번역 앱을 써도 괜찮아요.

韓国と日本の参加者が同じテーブルで話せるように、バランスを見ながら席を決めます。日本語を交ぜたり、翻訳アプリを使ったりしても大丈夫です。

50분마다 자리 바꾸기

15:50と16:40にテーブルを移ります。50分ずつ、計3回、違うメンバーとの会話を楽しめます。

交流会のあとは、希望する方で近くのお店へ夕食に行きます。二次会への参加は自由で、食事代は各自負担です。

    비밀번호는 모임 날짜마다 운영자가 직접 정합니다. 「저장 · 참가자 공개」를 누를 때 자리배정과 함께 저장되며, 서버에는 비밀번호 원문이 아닌 해시값만 저장됩니다. 기존 비밀번호는 다시 표시되지 않으므로 잊어버렸다면 새 비밀번호로 다시 공개해 주세요.

    테이블별 인원

    날짜와 설정을 고른 뒤 「랜덤 배정」을 눌러 주세요.

    국적 비율은 각 테이블의 정원에 맞춰 전체 한·일 비율과 가장 가까워지도록 나눕니다. 스탭은 가능한 한 서로 다른 테이블에 먼저 배치하며, 여러 회차를 만들면 이전 회차에서 만난 사람과 다시 같은 테이블이 되는 횟수도 줄입니다.
    이 탭은 본 모임(1차) 자리배정 전용입니다. 「저장 · 참가자 공개」를 누르면 자리배정이 날짜별로 D1에 저장됩니다. 이후 다른 날짜로 바꿨다가 돌아와도 저장된 TABLE 화면이 자동으로 다시 표시됩니다. 참가자는 seat.html에서 신청 이름 + 위 비밀번호로 현재 자리만 확인합니다.

    2차 참가자 체크

    이름을 눌러 참가자를 선택한 뒤 「랜덤번호 배정」을 누르면 선택 인원에게 1번부터 N번까지 중복 없이 랜덤으로 번호를 부여합니다.

    0명 선택
    랜덤 번호 결과

    참가자를 선택하고 「랜덤번호 배정」을 눌러 주세요.

    2차 체크 여부는 신청자 메모의 #2차 표시로 저장됩니다. 랜덤번호 결과도 D1에 날짜별로 저장되어 다른 휴대폰·PC에서 관리자 로그인 후 그대로 확인할 수 있습니다. 참가자 좌석 확인 페이지와는 연결되지 않습니다.

    첫 화면의 «지난주에는 …» 문구에 들어가는 숫자입니다. 비워 두면 입금이 확인된 인원으로 자동 계산됩니다. 실제 참석 인원이 다르면 여기서 고쳐 주세요.

    맨 위 요약 카드의 「일시 / 日時」 아랫줄에 이 글자가 그대로 들어갑니다. 고치는 즉시 뒤쪽 카드가 바뀌니 보면서 맞추시면 됩니다.

    음료 종류 관리 · 추가 / 이름 변경 / 숨김 / 삭제

    음료는 기본 4종을 포함해 최대 100종까지 등록할 수 있습니다. 기본 음료도 이름 변경·숨김이 가능하고, 추가한 음료는 삭제·복구할 수 있습니다. 특정 날짜만 품절/재판매하려면 아래 날짜별 버튼을 눌러 주세요. 이름을 바꾸면 기존 신청 내역의 표시 이름도 바뀌지만, 이미 발송된 메일은 바뀌지 않습니다.

    삭제한 음료 · 복구

    품절·신청 숨김은 신규 신청에만 적용됩니다. 기존 신청·발송된 메일은 자동으로 바뀌지 않습니다. 기존 참가자의 음료를 변경하려면 아래 신청 내역에서 수정하세요. 변경 시 안내 메일을 보냅니다.

    여는 중…

    매주 일요일은 자동으로 잡힙니다. 쉬는 주만 「휴무」로 바꾸면 신청 폼의 날짜 선택지에서도 빠집니다. 일요일이 아닌 날은 위에서 추가하세요.

    보내는 요일

    고른 요일의 그 시각에, 앞으로 있을 모임 중 가장 가까운 날짜의 명단을 보냅니다. 내용은 이름과 국적만 들어갑니다. 신청이 0명이어도 보냅니다.

    데이터 백업 메일

    매주 월요일 오전 10시(한국 시각) 이후, 신청자·페이지 문구·모임 날짜·자리 배정 등 운영 데이터를 표마다 CSV 로 묶어 자동으로 보냅니다. 받는 주소는 Worker 설정 BACKUP_MAIL(없으면 ADMIN_MAIL, 그것도 없으면 info@irotomo.com)입니다. 사진·로그인 기록·방문 기록은 넣지 않습니다. 참가자 개인정보가 들어 있으니 메일을 다른 사람에게 전달하지 마세요.
